# The Raw Ham's Lite Logger

A free, lite field logger and self-spotter for POTA, SOTA, WWFF, GMA, WWBOTA and LLOTA.
Runs on Windows, Android 8+ and Linux (including Raspberry Pi).

**Download page:** https://rawhamradio.github.io/rawham-lite-logger

- Windows: [Raw_Ham_Lite_Logger_Setup.exe](https://github.com/RawHamRadio/rawham-lite-logger/releases/latest/download/Raw_Ham_Lite_Logger_Setup.exe)
- Android: [RawHamLiteLogger.apk](https://github.com/RawHamRadio/rawham-lite-logger/releases/latest/download/RawHamLiteLogger.apk)
- Linux / Raspberry Pi: [Raw_Ham_Lite_Logger_Linux.zip](https://github.com/RawHamRadio/rawham-lite-logger/releases/latest/download/Raw_Ham_Lite_Logger_Linux.zip)
- Guide: [Guide.pdf](https://github.com/RawHamRadio/rawham-lite-logger/raw/main/Guide.pdf)

Free to use and share. Just don't sell it.
